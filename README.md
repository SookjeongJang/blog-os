# Blog OS 프로토타입

## 실행 방법
1. 압축을 풀어요.
2. `index.html` 파일을 더블클릭해요.
3. 휴대폰에서는 GitHub Pages 또는 Vercel에 올리면 앱처럼 사용할 수 있어요.

## 현재 기능
- 오늘 추천 글감 보기
- 카테고리 필터
- 작성 목록으로 이동
- 발행 대기로 이동
- 글감 추가 테스트
- 비용 절약 모드 설정
- 다크/라이트 테마
- 브라우저 로컬 저장
